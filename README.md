# News

Personal AI/tech/economics reading list and discussion workspace. Drop links, discuss with an agent, add the good stuff to the table.

## How it works

1. Drop a link (article, podcast, video) into a conversation
2. Discuss it — argue, steelman, pull out the interesting bits
3. If it stands out, add it to [`resources.md`](resources.md)

## Tools

```bash
bun run pdf-to-md <file.pdf>   # extract PDF text to markdown
bun run check                  # lint + format + test
```

## Data

[`resources.md`](resources.md) is the single curated table of resources maintained in this repo. Everything else is conversation.
